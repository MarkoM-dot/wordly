# Installation

Install wordly using a package manager. You are encouraged to create a virtual environment.

```sh
python -m venv .venv
source .venv/bin/activate
pip install wordly
```

If you are using `uv` you may install wordly as a tool and make use of the cli tool immediately:

```sh
uvx wordly recalcitrant
```

If you are using `pipx` and have the cli tool available to you globally:

```sh
pipx install wordly
```
